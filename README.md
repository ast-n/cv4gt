# cv4gt
Computer Vision for garbage truck driver safety

### Run the current demo
```python

python demo.py --video input.mp4 --output output.avi

```

## Training

The model was trained on a custom dataset using YOLOv8. The training notebook is available in the repository.

To train your own model:

1. Upload your dataset to Roboflow
2. Update the training notebook with your Roboflow API key and project details
3. Run the training notebook
